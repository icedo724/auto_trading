# 데이터 소스 가이드 — 무엇이 무료이고 무엇이 유료인가

## 결론 먼저

**백테스트·시뮬레이션에 필요한 데이터는 전부 무료다.**

흔한 오해는 "주가 데이터 = 실시간 시세 = 유료"인데, 이 둘은 완전히 다른 상품이다.

| | 필요한 것 | 비용 | 이 프레임워크에서 |
|---|---|---|---|
| **백테스트 / 파라미터 최적화** | 과거 일봉(EOD) | **무료** | 이걸 쓴다 |
| **일 1회 신호 생성 후 수동 주문** | 전일 종가 또는 지연 시세 | **무료** | `quant signal` |
| **장중 자동매매 (분/초 단위)** | 실시간 체결·호가 | **증권사 계좌만 있으면 무료** | 별도 연동 필요 |
| **초단타(HFT)·기관 배포** | 코스콤 직수신, 유료 벤더 | 유료 (월 수십만~) | 대상 아님 |

이 프레임워크는 **일봉 기준**이다. `t`일 종가로 신호를 만들어 `t+1`일 시가에 체결하는
모델이므로 실시간 시세가 원리적으로 필요 없다. 하루 한 번 종가만 받으면 된다.

## 1. 무료 — 과거 일봉 (백테스트용)

### 권장: FinanceDataReader

```bash
pip install finance-datareader
```

```yaml
data:
  source: fdr
  symbols: ["005930", "000660"]
```

- 인증 불필요, 국내(KRX 전종목) + 미국 + 지수 + 환율 + 암호화폐를 한 인터페이스로
- 내부적으로 네이버 차트 서버(`fchart.stock.naver.com`)를 사용
- 심볼: 국내 `005930`, 미국 `AAPL`, 지수 `KS11`(KOSPI) `KQ11`(KOSDAQ), 환율 `USD/KRW`

### 대체: 네이버 금융 직접 호출

```yaml
data:
  source: naver
```

- **의존 패키지 없음** (`requests`만). FDR이 막혔을 때의 우회로
- 비공식 엔드포인트라 스펙이 예고 없이 바뀔 수 있다

### pykrx (KRX 정보데이터시스템)

```bash
pip install pykrx
```

```yaml
data:
  source: krx
```

- 일봉 외에 **투자자별 매매동향, 시가총액, PER/PBR, 공매도** 등 KRX 고유 데이터 제공
- pykrx 1.2 부터 KRX 로그인을 **선택적으로** 지원한다.
  자격증명이 없으면 익명 세션으로 폴백하므로 그냥 써도 동작하지만, KRX 측 요청 제한에
  더 민감하다. 안정성이 필요하면 KRX 계정을 만들어 환경변수로 넣는다.

  ```bash
  export KRX_ID="your_id"
  export KRX_PW="your_password"
  ```

### yfinance (해외)

```bash
pip install yfinance
```

```yaml
data:
  source: yahoo
  symbols: [SPY, QQQ, AAPL]     # 국내는 005930.KS 형태
```

- 비공식 API. 조회 빈도가 높으면 일시 차단될 수 있다(캐시가 이를 완화한다)

### 그 외 무료 EOD 소스

| 소스 | 특징 |
|---|---|
| **KRX 정보데이터시스템** (data.krx.co.kr) | 공식. 웹에서 CSV 직접 다운로드 → `source: csv` |
| **공공데이터포털** (data.go.kr) 금융위 주식시세정보 | 공식 REST API. 무료 인증키 발급 필요. 일 트래픽 제한 |
| **Stooq** (stooq.com) | 글로벌 EOD, CSV 직링크, 무인증 |

## 2. 무료 — 실시간 시세 (실전 자동매매용)

**국내 증권사 Open API는 계좌만 있으면 실시간 시세가 무료다.** 별도 데이터 이용료 없음.

| 증권사 | API | 실시간 | 환경 | 모의투자 |
|---|---|---|---|---|
| **한국투자증권** | KIS Developers (REST + WebSocket) | O | OS 무관 | O |
| **키움증권** | 키움 REST API / OpenAPI+ | O | REST는 무관, OpenAPI+는 Windows 32bit | O |
| **LS증권** | XingAPI | O | Windows | O |
| **대신증권** | CYBOS Plus | O | Windows | X |

**한국투자증권 KIS**를 권하는 이유: REST + WebSocket이라 OS를 안 가리고,
문서가 공개되어 있으며, **모의투자 계좌를 지원**해서 실제 돈 없이 주문 로직까지
검증할 수 있다.

> 주의: 실시간 시세가 무료라는 것과, **초당/일별 호출 한도가 있다**는 것은 별개다.
> 종목 수가 많으면 한도 설계를 먼저 해야 한다.

## 4. 내 환경에서 뭐가 되는지 확인하기

```bash
python -m quant check-data
```

각 소스로 최근 30일 일봉을 실제로 받아보고 결과를 표로 알려준다.
사내망·방화벽 환경에서 어떤 소스가 막혔는지 바로 판별할 수 있다.

```
데이터 소스 진단
==============================================================================
소스          상태         봉수  구간                             소요
------------------------------------------------------------------------------
synthetic   정상         23  2026-06-29 ~ 2026-07-29      0.0s
fdr         정상         21  2026-06-30 ~ 2026-07-29      1.2s
naver       정상         21  2026-06-30 ~ 2026-07-29      0.4s
krx         실패          0  -                            2.1s
            └ 005930: pykrx 응답이 비어 있습니다. ...
------------------------------------------------------------------------------
사용 가능한 실시세 소스 2개: fdr, naver

설정 파일에 다음과 같이 지정하세요:
    data:
      source: fdr
```

특정 소스만 점검하려면:

```bash
python -m quant check-data --source fdr --symbol 035720
```

## 5. 캐시

원격 소스는 자동으로 `data/cache/<소스>/<종목>.csv` 에 저장된다.
요청 구간이 캐시에 모두 들어 있으면 네트워크를 타지 않으므로,
그리드 탐색을 반복해도 서버에 부담을 주지 않는다.

```bash
python -m quant fetch -c configs/experiment_kr.yaml            # 캐시 채우기
python -m quant fetch -c configs/experiment_kr.yaml --refresh  # 강제 갱신
```

캐시를 채워두면 **완전 오프라인**으로 최적화·검증을 돌릴 수 있다.

## 6. 데이터 품질에서 반드시 확인할 것

무료 소스를 쓸 때 백테스트 결과를 망치는 전형적인 함정들이다.

**① 수정주가(액면분할·유상증자 반영)**
FDR·pykrx(`adjusted=True`)·yfinance(`auto_adjust=True`)는 수정주가를 준다.
수정 전 가격을 쓰면 분할일에 -50% 폭락이 찍혀 손절이 줄줄이 발동한다.

**② 생존 편향(survivorship bias)**
현재 상장된 종목만 유니버스에 넣으면, 상장폐지된 실패 사례가 통째로 빠져
성과가 과대평가된다. 이 프레임워크도 유니버스가 고정이라 이 편향이 남아 있다.
보수적으로 해석하고, 가능하면 과거 시점의 구성종목 목록을 따로 확보하는 게 좋다.

**③ 거래정지·관리종목**
거래정지 기간에는 가격이 그대로 유지되다가 재개 시 급변한다.
백테스트는 그 구간에도 체결이 됐다고 가정하므로 실제와 어긋난다.

**④ 유동성**
거래대금이 작은 종목은 슬리피지 가정(기본 5bp)이 전혀 맞지 않는다.
일평균 거래대금 하한을 두고 유니버스를 거르는 것이 안전하다.
